### Proyectos Compartidos

#### 1. Siniestralidad: Riesgos Espaciales (Prueba de Concepto)
Prototipo analítico (*Proof of Concept*) diseñado para evaluar la concentración geográfica de carteras de seguros y medir el índice de siniestralidad por zona. Utiliza lógica de *Crossfilter* en el frontend para recalcular la distribución de pólizas, sumas aseguradas y niveles de riesgo en tiempo real mediante mapas coropléticos interactivos. 

> 🔒 **Nota Técnica de Seguridad:** Este desarrollo en HTML autónomo sirve como demostración de lógica matemática, limpieza de datos y modelado espacial. Para un entorno de producción corporativo, mi objetivo es integrar estos algoritmos backend trabajando en conjunto con equipos de Arquitectura de Datos y TI para garantizar el despliegue seguro en servidores bajo normativas de confidencialidad y bases de datos encriptadas.
